# fl_to_do_list

Uma aplicação simples de lista de tarefas (To‑Do) construída com React + Vite.

Este repositório contém um exemplo prático de app de tarefas com foco em componentes React, roteamento e estilização com TailwindCSS.

Acesse a aplicação no [*Link*](https://to-do-lilst.vercel.app/).

Principais tecnologias

- React 18
- Vite (ferramenta de build/dev)
- TailwindCSS (estilos)
- react-router-dom (rotas)
- uuid (geração de IDs)
- lucide-react (ícones)

Instalação

1. Clone o repositório:

   git clone https://github.com/FlavioFj20/fl_to_do_list.git
2. Instale dependências:

   npm install
3. Rode em modo de desenvolvimento:

   npm run dev

O servidor de desenvolvimento do Vite normalmente abre em http://localhost:5173.

Scripts úteis (package.json)

- npm run dev — inicia o servidor de desenvolvimento
- npm run build — gera a build de produção
- npm run preview — serve a build gerada para testes locais
- npm run lint — executa o ESLint no código

O que esperar desta aplicação

Estrutura sugerida do projeto

- src/ — código fonte React (componentes, páginas, estilos)

- package.json — dependências e scripts
